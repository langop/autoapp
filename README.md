# Bili UP Viewer

Electron 桌面工具：查询 B 站 UP 主资料、本地收藏，并按需浏览动态与评论；支持单个 UP 的新动态桌面提醒，以及关闭到托盘后台驻留。

当前版本 `0.1.0`，主要面向 **Windows**（托盘、通知、NSIS 安装包）。

## 功能

### 查询与资料

- 首页输入 UID 查询 UP 主
- 资料页展示头像、昵称、等级、粉丝数、签名
- 一键收藏 / 取消收藏；进入动态列表

### 本地收藏

- 收藏保存在本机，与 B 站账号无关
- 卡片展示头像、昵称、UID
- 拖拽卡片调整顺序并持久化
- 单卡 **提醒** 开关；**取消收藏**（确认后删除）
- 点击卡片进入该 UP 的动态

### 动态

- 按天分组展示（今天 / 昨天 / 星期），置顶单独分区
- 支持刷新、分页加载更多
- 类型标签：视频 / 图文 / 文字 / 专栏 / 转发 / 直播等
- 封面与多图网格；点击图片打开灯箱浏览
- 视频 / 番剧可在应用内播放器打开（弹幕关闭、自动播放）
- 点击动态进入评论区

### 评论

- 按 **时间** / **热度** 排序
- 分页加载；楼层、点赞、时间；嵌套回复（部分）
- UP 本人评论带标识
- 表情包渲染；评论区图片同样可点开灯箱
- 灯箱支持上一张 / 下一张、滚轮与按钮放大缩小（约 1×–5×）、拖拽平移、双击切换缩放、Esc 关闭

### 动态提醒

- 设置页总开关（默认开启）+ 检查间隔（默认 15 分钟，范围 5–60）
- 收藏卡上可为单个 UP 开启提醒（默认关闭）
- 仅在应用进程运行期间轮询；真正退出后不再检查
- 新动态：Windows 桌面通知 + 应用内 Toast；点击可跳转到该 UP 动态
- 首次开启或首次见到某 UP 会写入基线，不弹提醒；之后内容变化才通知
- 忽略置顶动态对「最新」的干扰

### 关闭与托盘

- 关闭行为可配置：`每次询问`（默认）/ `最小化到托盘` / `退出应用`
- 点关闭 `×`：可驻留托盘继续收提醒，或退出；可勾选「记住我的选择」
- 最小化 `_` 仍落到任务栏（不进托盘）
- 托盘：左键 /「打开」恢复窗口；「退出」结束进程

### Cookie 与数据隔离

- 默认不登录；公开接口受限时可配置 Cookie（`SESSDATA` 等）
- 设置页粘贴保存 / 清除，立即生效，无需重启
- 开发环境：设置页为空时可用环境变量 `BILI_COOKIE` 回退
- **安装包（正式版）不使用环境变量 Cookie**，也不携带开发机上的收藏 / Cookie
- 用户数据目录（Windows `%APPDATA%`）：
  - 开发：`bili-up-viewer-dev`
  - 正式版：`Bili UP Viewer`
- 本地文件：`favorites.json`、`settings.json`、`watch.json`

## 要求

- Node.js 20+
- 开发可在 Windows / macOS / Linux 运行；打包与托盘/通知以 Windows 为主

## 使用

```bash
npm install
npm start
```

### 设置 Cookie（推荐）

应用内：首页「已收藏」右侧 **设置**，粘贴浏览器 Cookie，保存后立即生效。

开发环境也可在设置页为空时用环境变量回退：

```powershell
$env:BILI_COOKIE="SESSDATA=...; bili_jct=..."
npm start
```

## 打包（Windows）

```bash
npm run icons   # 生成窗口 / 托盘 / 安装图标
npm run pack    # 未打包目录：dist/win-unpacked
npm run dist    # NSIS 安装包：dist/Bili UP Viewer Setup 0.1.0.exe
```

安装包可选安装目录，并创建桌面与开始菜单快捷方式（名称：`Bili UP Viewer`）。

## 说明

- 只读浏览：不发评、不点赞、不写站内操作
- 请求经主进程转发；图片走本地代理以避免 CDN 防盗链
- 提醒与托盘驻留依赖进程存活；关闭到托盘时仍会继续检查动态
