# 关闭窗口：询问 / 托盘常驻 / 退出 — 设计文档

**日期：** 2026-08-12  
**状态：** 已确认  
**关联：** Bili UP Viewer（Electron）；动态提醒仍仅在进程存活时轮询

## 目标

关闭主窗口时，用户可选择「最小化到托盘」或「退出应用」；支持记住选择，并在设置中随时修改。托盘常驻时提醒定时器继续运行。

## 非目标

- 开机自启
- 改变现有动态提醒轮询逻辑（间隔、游标、首次不误报等）
- 自定义无边框标题栏
- 最小化按钮（`_`）进托盘（`_` 仍只进任务栏）

## 已确认决策

| 项 | 决策 |
|---|---|
| 点 × 默认 | 弹出询问（退出 / 最小化到托盘） |
| 记住选择 | 对话框可勾选「记住我的选择」，写入设置 |
| 事后修改 | 设置页「关闭窗口时」三项可选 |
| 最小化 `_` | 保持系统默认，进任务栏 |
| 提醒 | 进程在则继续轮询；真正退出则停止（与现逻辑一致） |

## 数据

### 设置扩展（`settings.json`）

新增：

- `closeAction: 'ask' | 'tray' | 'quit'`
  - 默认：`'ask'`
  - 非法 / 缺失值：回退 `'ask'`

保存设置时与现有 `cookie` / `notifyEnabled` / `notifyIntervalMin` 一并读写。

## 界面

### 设置页

在「动态提醒」区块附近增加：

- 标签：关闭窗口时
- 控件：单选或下拉
  - 每次询问
  - 最小化到托盘
  - 退出应用
- 保存后立即生效（无需重启）

### 关闭询问对话框（仅 `closeAction === 'ask'`）

使用主进程系统对话框（`dialog.showMessageBox`），避免自定义 HTML 模态与系统关闭竞态。

- 文案大意：关闭窗口后是否继续在后台接收动态提醒？
- 按钮：`最小化到托盘`、`退出应用`、`取消`（取消则窗口保持打开）
- 复选：`记住我的选择`  
  - 勾选且选托盘 → 写入 `closeAction: 'tray'`  
  - 勾选且选退出 → 写入 `closeAction: 'quit'`  
  - 未勾选或点取消 → 不改设置；取消时本次不关闭

### 系统托盘

- 应用就绪后创建 `Tray`（Windows）
- 图标：优先应用图标；开发态可用 Electron 默认图标兜底
- 左键单击：显示并聚焦主窗口
- 右键菜单：
  - 打开
  - 退出（真正 `app.quit()`）

托盘在 `closeAction === 'quit'` 且用户未进托盘时仍可创建（便于后续改设置后首次进托盘），或仅在首次需要托盘时创建；实现上**启动即创建托盘**更简单，退出时销毁。

## 主进程行为

1. 拦截主窗口 `close` 事件：
   - 若已标记 `isQuitting === true`（托盘「退出」或 `app.quit()`）：放行，正常关闭
   - 若 `closeAction === 'tray'`：`event.preventDefault()`，`mainWindow.hide()`
   - 若 `closeAction === 'quit'`：放行
   - 若 `closeAction === 'ask'`：`preventDefault()`，弹出对话框，按结果 hide 或进入退出流程
2. `window-all-closed`：若仍因托盘常驻而未退出，**不要** `app.quit()`（Windows 上隐藏窗口后通常已无可见窗，需跳过默认退出）
3. 托盘「退出」：设 `isQuitting`，`tray.destroy()`，`app.quit()`
4. `before-quit`：继续 `scheduler.stop()`（现有逻辑）

点击桌面通知聚焦窗口的现有逻辑保持不变；若窗口被 hide，通知点击应 `show` + `focus`。

## 错误与边界

- 对话框打开期间再次点 ×：忽略或串行，避免叠多个对话框
- 托盘创建失败：回退为直接退出，并尽量 `console.error`；不静默卡死无法退出
- 多显示器 / 最小化后再 hide：`show()` 时 `restore()` + `focus()`

## 测试要点

- `settings`：`closeAction` 默认 `ask`；非法值回退；`save` 合并更新
- 主进程关闭分支可用轻量纯函数测决策：`resolveCloseAction({ closeAction, isQuitting }) → 'allow-quit' | 'hide' | 'ask'`（对话框本身用手动冒烟）

## 验收

1. 默认点 × 出现询问；选托盘后窗口消失，进程仍在，提醒可继续  
2. 勾选记住并选托盘后，再点 × 不再询问，直接进托盘  
3. 设置改为「退出应用」后，点 × 进程退出  
4. 托盘「打开」恢复窗口；「退出」结束进程  
5. `_` 最小化仍进任务栏，不进托盘
